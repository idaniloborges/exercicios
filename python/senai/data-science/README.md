# Criar aplicação

## 1- Abrir o prompt de comando e instalar a biblioteca auto-py-to-exe utilizando o comando abaixo:
```bash
pip install auto-py-to-exe
```

## 2- Após a instalação, iniciar o programa utilizando o seguinte comando: 
```bash
auto-py-to-exe
```
ou, caso não funcione, a aplicação também pode ser iniciada com o seguinte comando:
```bash
python -m auto_py_to_exe
```
## 3- Após iniciado, selecionar o endereço em Script Location da aplicação e o ícone em Icon.

## 4- Clicar em Converter .py to .exe.

## 5- Ir até o local da aplicação e testar se funciona.
